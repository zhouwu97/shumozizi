# 高级图表补充

只为解释数学对象、决定性证据、机制或边界补图。新运行不设逐问或全篇数量合同；旧 `competition-quality-v1` 运行保持兼容。每张图必须说明观察、机制和结论，禁止重复表格、换色拆图和装饰图。

先在 Visual Sandbox 生成结构不同的候选，再用当前数据和正式 renderer 重建。正式图必须检查 PNG/PDF 几何一致性、字号、黑白可读性、正文栏宽和图注。图数量不足是编辑信号，不得阻断科学写作或促使作者虚构图。
