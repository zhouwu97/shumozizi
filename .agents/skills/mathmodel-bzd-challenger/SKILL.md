# BZD 挑战器（按需）

本技能的职责是攻击当前主路线的最高风险，不是再建立一套平行生产流程。默认输入为冻结的题意合同、主路线和待区分假设；输出必须能被当前统一 scorer 或独立复算检验。

## 何时使用

只有以下情况才启动：主路线和 challenger 仍无法裁决、首个可行解后仍有明显上升空间、语义反例需要隔离复核，或稳定论文需要一次专项外部评委阅读。普通运行不自动创建 Solver B 和 Scientific Jury。

## 挑战方式

- 结构 challenger：只改变一个数学结构或信息假设，不复制整道题的生产目录。
- 交叉复算：检查同一个 production result 的目标、约束、账本和关键数值。
- 论文攻击：只读冻结 PDF，提出最多五项最高价值修改。

挑战结果必须返回统一 scorer、最小反例、实际代码或 PDF 位置，以及明确的“支持、推翻或不确定”。未产生可执行区分实验时，不得让挑战报告升级为路线或答案。

保留 `scripts/dual_solver/prepare_solver_b.py` 和 `run_scientific_jury.py` 作为旧运行兼容入口；新运行只有在负责人明确选择第二套完整求解时才调用它们。
