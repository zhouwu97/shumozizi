# 离线论文学习

此 Skill 只提升后续能力，不修改任一 `runs/<run-id>/state/run.json`，不阻断当前赛题，也不自动将历史方法套到新题。

1. 清点本地论文、对应原题、来源身份、页码、许可证和文件哈希；原题、页码或来源不明确时记录原因并停止建卡。
2. 生成 `knowledge/cards/papers/<paper_id>.md`，记录题目类型、数据结构、统计单位、问题链、共享数学对象、模型选择理由、baseline、验证、图表叙事、摘要写法、可迁移模式、不可迁移内容、缺陷、复现风险和来源页码。学习 PDF 时必须实际渲染并查看重要图所在页，逐图回答支持的结论、数学对象、表格为何不足、关键元素、阅读顺序、装饰元素、不可迁移部分和现有 renderer 可实现性；OCR 只能辅助读取标签，不能代替看图。重要图在 `## 视觉模式` 中用 YAML 登记 `visual_archetype`、信息结构、面板布局、阅读顺序、可见元素、`required_data_fields`、适用/不适用条件和可迁移原则；`required_data_fields` 只写新题必须真实提供的结构字段，例如 `candidate_points`、`feasible_mask`、`active_constraints`，不得保存来源坐标、数据、标签、代码或图注。能从原题与论文可靠判断时，可追加五个失败模式小节：`关键题意裁决`、`最诱人的错误解释`、`最小判别反例`、`分解的成立条件`、`结论有效范围`；无法判断则省略，不能臆造。
3. 优先提炼结构模式、视觉模式和失败边界，尤其记录看似自然却错误的聚合、量词或分解方式及其最低成本识别方法。不复制原论文的数字、结论、代码、原始公式段、坐标、独特配色或未经许可的段落，也不根据文件名自动判断其奖项或质量。
4. 运行 `python scripts/knowledge/build_index.py` 重建 `knowledge/indexes/papers.json`，并验证卡片 ID、结构标签、来源路径和哈希可追溯。索引是可重建资产，不是当前运行状态。
5. 按结构空白扩充卡库：统计/重复测量与删失、多目标决策、机理仿真、时空网络，以及有明确缺陷的反例。优先少量高质量卡，不按数量证明覆盖度。

## 与生产论文的单向边界

本 Skill 不读取运行目录、不接收当前题的结果 ID，也不触发 `$mathmodel-paper`。它产出的论文卡始终是离线能力资产，而不是当前题的事实、数值或结论来源。知识卡或索引更新不得通过哈希反向失效既有实验、科学挑战或结果。

生产主链不调用本 Skill，而由 `scripts/knowledge/retrieve_for_run.py` 受控消费索引：analysis 在路线竞争前按数据结构、统计单位、数学困难、目标/约束、验证风险和问题继承检索，最多保留 3 张结构相似卡、每卡 2 个模式并逐项采用或拒绝；卡片存在视觉模式或失败模式小节时，检索结果会同时携带安全的结构提醒，但不作为当前题答案。采用模式必须使用类型化应用层绑定当前建模单元、验证合同、图计划或论文结构，并登记适配动作和可推翻条件；paper 默认只重新判断分析已采用项，分析已拒绝项自动继承，只有显式 reopen 才重开。`KNOWLEDGE_APPLICATION.md` 最多选择 1--2 张卡，采用项写明应用位置、当前题证据、实际正文源码和兑现锚点。编译前必须打开源码复验锚点。无相关匹配时明确记录，不强行选卡。

PDF 独立盲评仍只读取冻结 PDF，不能接收知识卡、检索记录或写作计划。盲评完成后，本地 `CUMCM_LAYOUT_AUDIT` 才可检查预先选定的模式是否在 PDF 中兑现；该检查保持 advisory，只评价计划兑现，不评价是否达到某篇论文或某个奖项水平。

卡或其原论文中的数值、结论、代码、原始公式段和实验结果不得迁移到当前论文，且卡不能作为 citation、evidence、Claim-Evidence、结果引用或事实来源。当前论文的所有事实、图表、表格和结论只能来自本次 run 的 production/current/accepted 证据链。
