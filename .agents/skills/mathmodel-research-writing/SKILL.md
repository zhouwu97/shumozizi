# 按需写作辅助

本 Skill 不在 v3.1 主动 Skill 列表中。`mathmodel-paper` 可按需调用它来展开正文，但只使用当前结果、有效图表、洞察和 answer map。

优先帮助作者明确最强问题、最弱问题、章节职责、非对称篇幅、主张到证据再到机制解释和诚实边界。不要要求 `method_profile`、`critical_claims`、手工 argument map、固定图种、固定字数或每问相同段落模板。

摘要最后写，避免模型名堆砌。普通问题只需正确直接回答；题目特定贡献最多三项，并且必须能相对 baseline 和当前证据说清楚。
