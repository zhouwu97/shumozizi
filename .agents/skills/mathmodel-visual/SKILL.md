# 论证驱动图表

每个图先写一条 figure contract：核心结论、证据链、读者一眼应看到什么，以及删掉它论文会失去什么。答不出最后一项就不画。先按定量网格、示意图主导组合、图像加定量或混合模态判断构图，再决定是否需要主图和辅助面板。正式图必须由当前 production 数据和确定性 renderer 生成，草图不能冒充证据。

## Sandbox

在 `figures/visual-ideas.json` 和 `figures/sandbox/<idea-id>/` 中自由尝试普通图、机制图、示意图、合并图或拆分图。草图阶段不要求 manifest、caption、LaTeX label 或结果绑定。关键 insight 可做 2–3 个结构不同的候选，reviewer 只比较哪张最清楚、哪张最少重复、哪张最值得占正文版面。多面板只合并共同支撑一个判断且共享尺度、图例或阅读方向的内容，不为凑图型拼接无关小图。

## 正式图

胜出草图只冻结为 design reference；随后必须从 current 数据在 `figures/work/<figure_id>/<version>/` 重新生成，检查 PNG/PDF、字号、比例、图例、黑白可读性和正文栏宽，通过后进入 `figures/current/`，旧版进入 `figures/archive/`。

图表角色包括模型理解、决定性证据、机制、比较和边界。优先一张承担中心判断的 hero panel，再用少量不可替代的面板补充机制或边界；一个问题可以共享图、没有 hero，或只保留一张主图。空间、集合、网络、决策面和区间结构优先用真实结构原型；普通折线、散点或柱图最清楚时直接使用。统一字体、低饱和方法色和一个强调色，短图题把解释留给正文。

优先复用内置科研模板作为构图起点：相关性、雨云、Taylor、ROC、决策面、Sankey 和多面板证据链使用对应模板；技术路线、研究框架和算法流程使用可编辑示意图模板。模板只提供视觉语言，数据、结论和图中文字必须由当前运行重新生成。

新运行不设置“每问 2–3 张”“全文 13–18 张”或“至少三种图型”的硬门；这些要求仅对显式 `competition-quality-v1` 旧运行兼容。新运行只检查关键判断有 current 证据、图在正文可读、图注解释观察—机制—结论。

## PDF 视觉编辑

冻结 PDF 后做一次只看成品的开放冷读，最多保留五项最高价值意见：主图是否真的在讲判断、是否存在表格重复、是否有连续公式堆叠、关键对象和边界是否可见。视觉意见默认 advisory；只有图使用了错误数据、图文事实不一致或图不可读才阻断。
