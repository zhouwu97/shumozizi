# 竞赛论文撰写

本 Skill 负责把当前运行的真实模型、推导、结果和科研图表组织成高质量学术竞赛论文。它不搜索网络、不查找同题答案、不复制优秀论文内容，也不生成没有证据的章节。

---

## 篇幅重心与篇章结构

正常国赛建模论文，正文视觉与内容重心必须显著集中于**模型建立、数学推导、求解与结果机制解释**（建议占比 50–60%）：

```text
问题重述/分析       较短（直奔困难与核心矛盾）
假设/符号           较短（紧凑精炼，必要假设说明作用）
模型建立 + 推导     最大块（核心公式、等价变换、约束物理意义）
模型求解 + 算法     大块（算法选择理由、求解步骤、Baseline 对比）
结果分析 / 机制     大块（为什么呈现当前结构、活跃约束、边际收益）
验证 / 敏感性       中等（参数扰动、极端情况、适用边界）
评价 / 推广         较短（客观优缺点、实际推广场景）
```

## 核心写作原则

### 1. 模型不能只报名字，必须给出选择理由
正文中禁止直接写“本问采用遗传算法求解”。必须回答：
- 为什么需要数值搜索或特定模型？为什么不能直接解析求导？
- 决策变量空间维度是多少？约束有什么几何/代数特点？
- 为什么这种算法适合当前问题的维度和约束结构？
- 是否有更简单的 Baseline？如果有 Baseline，相比它升级了什么？取得了多少改进？

### 2. 关键数学关系必须展开推导
优秀建模论文不能只展示“题意 → 代码 → 结果表”。真正改变解法或决定模型成立的关键推导必须展示在正文中：
- **几何/空间问题**：几何定义 → 表面距离/相交判定条件 → 等价变换 → 判据公式。
- **状态/时序问题**：状态变量 → 转移方程 → 事件触发条件 → 守恒关系与递推。
- **评价/优化问题**：指标定义 → 标准化与权重 → 目标函数与约束展开 → 求解形式。

### 3. 参数定量依据
模型中的关键参数、阈值或超参数必须说明定量来源：
- 来自题面直接给定或附件统计估计；
- 物理/工程先验常数；
- 灵敏度网格搜索或交叉验证确定。
禁止无来源突兀出现关键常数。

### 4. 重要结果必须解释产生机制
不仅报告数值（如“$f^* = 1.24\%$”），更要解释：
- 为什么最优解呈现当前形态？
- 哪个约束是活跃约束（紧约束），控制了最优边界？
- 随着资源/参数增加，收益呈现何种趋势（线性、边际递减、拐点突变）？
- 最差情况或边界情况发生了什么？

### 5. 图文必须完成“观察 → 机制 → 结论”
每张正式图在正文中必须完成完整三步论证，不得以一句话带过：
- **图显示了什么？**（数据直觉与形态特征，如狭长带状、单调上升、双峰分布）；
- **为什么呈现这种结构？**（底层模型原因、物理机理、几何约束或变量耦合）；
- **这对当前模型/结论意味着什么？**（支持了哪个判断、排除了哪种假设、对决策有何指导）。

### 6. 正文以连续学术段落为主
- 正文的主要论证必须使用连贯、逻辑紧密的学术段落，每段首句通常为主题句。
- 列表仅适合：必要模型假设、符号说明表、极少量算法步骤、模型优缺点摘要。
- 严禁把模型推导、结果分析和机制解释写成 bullet list 汇报。

### 7. 自然克制的学术语言
- 采用正式、严谨、克制的中文数学建模学术表达。
- 允许使用“本文建立……”、“本文定义……”、“由式(x)可得……”、“这说明……”、“其原因在于……”等自然学术表达。
- 严禁使用“我们/大家”等口语化第一人称；严禁工作汇报式语气和“效果极其显著”等自我吹捧词。

## 摘要写作规范（最后写）

摘要是评委的第一印象，应在论文主体完成后最后撰写，采用 6 步紧凑结构：
1. **背景与核心困难**（1 句，指出问题非显然的数学或实际挑战）；
2. **共享建模对象与关键思路**（1–2 句，如何将问题转化为可解的数学模型）；
3. **主要求解方法**（1 句，采用的算法或求解框架及其适配性）；
4. **逐问核心数值结果**（精确数字，含单位与直接答案，不以 Q1/Q2 报账编号机械隔开）；
5. **结果规律与机理洞察**（发现了什么边际规律、瓶颈或权衡）；
6. **可信边界与敏感性**（关键假设与结论成立的条件边界）。

## 选择模板与编译

在 `visualization -> paper` 前调用模板选择器：

```powershell
python scripts/paper/select_template.py runs/<run-id> `
  --language <zh|en> --engine auto `
  --reason "比赛、语言与仓内模板匹配；优先 LaTeX。" --materialize
```

完成后编译论文：

```powershell
python scripts/paper/compile_paper.py runs/<run-id>
```

之后对生成的 PDF 进行匿名 Editorial Pass 与盲审，重点审阅页面排版密度、推导深度与图文论证质量，直接针对源文件进行优化。
