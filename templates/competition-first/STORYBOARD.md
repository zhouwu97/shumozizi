# 论文中心问题

本文真正需要解释或证明的核心是什么？（不是"我们建立了什么模型"，而是"这道题中什么事情需要被解释清楚"）

# 中心判断

最终主张什么？用一句能被反驳的陈述写出来。

# 论证链

1. 从哪些题面事实出发
2. 导出什么数学关系（哪些是解析的，哪些是数值的）
3. 哪一步真正需要数值求解（不是所有步骤都是数值的）
4. 什么计算证据支持结论
5. 哪种替代解释被排除，怎么排除的
6. 结论在哪些边界内成立

# 核心矛盾

效率、均衡、安全、资源之间的主要冲突是什么？不同目标之间如何权衡？
