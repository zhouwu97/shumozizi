# academic_bilingual_infographic_v1

这是论文级双语信息图的风格契约，不是题目内容或答案来源。

- 顶部使用中文主标题和英文副标题，随后用 INPUT / MODEL / JUDGMENT / SOLVE / OUTPUT 形成阅读导航。
- 主体按阶段用低饱和蓝、紫、橙、青绿、深绿分区；每个阶段内部必须有标题、英文小字、语义图标、子卡片和至少一个公式或关系示意。
- 核心数学对象占最大视觉面积；网络、状态、队列、时间轴、曲线、阈值和决策节点应以真实小图表达，而不是只写成标签。
- 使用深灰箭头、严格对齐、适度圆角和出版物级留白；留白服务于分组，不得出现大片无意义空区。
- 底部保留一句方法总结或边界说明，必要时附短符号说明；关键结果必须绑定 current 结果。
- 禁止把“几个白框加箭头”当作信息图，禁止软件架构图和普通 DrawIO 模板感。
