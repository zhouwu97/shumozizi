# 写作交接说明

本包是运行 `{{RUN_ID}}`（题目 `{{PROBLEM_ID}}`，必答问题 `{{REQUIRED_QUESTIONS}}`，交接修订 `{{HANDOFF_REVISION}}`）的研究材料。

你负责撰写数学建模竞赛论文。所有科学结果已经由上游模型、实验和独立审核冻结。

你的任务不是重新求解问题，而是把已有研究材料写成完整、自然、有数学论证深度的竞赛论文。

## 核心规则

- 每个核心问题开头先用 2–4 句直接给出答案，方便评委快速定位；正文根据本问实际新增内容展开，不要求机械使用固定小标题。后续问题可直接继承前文已经定义的共享模型、符号和通用求解过程，只需讲清新增或改变的约束、关键数学处理、主要结果与直接答案。
- 逻辑证明必须就近保留：上下界、构造、关键不等式与约束可行性应放在对应问题中，不能用统一验证章节替代。实现验证全文集中一次：MATLAB 独立复算、Python 重放、批量通过率、MIP gap 和环境一致性等共同核验，不要为了“每问有 validation”反复报告；细节过长时移入附录。
- 允许：重组章节、连续写作、展开已有推导、调整段落顺序、改善过渡、调整各问篇幅、组织图表叙事、合并重复内容、提升文风。
- **禁止**：修改正式答案、改变目标函数语义、改变约束、创造新结果、编造实验、编造敏感性结论、编造图、编造引用、升级主张边界。

## 事实边界

逐问"必须回答 / 可以安全表达 / 禁止升级 / 关键边界"见 `ANSWER_AND_CLAIMS.md`，这是最重要的边界文件。写作时任何数字、比较、强度词（全局最优、唯一、显著、鲁棒、稳定、证明、泛化、必然）都必须落在该文件声明的范围内。

## 材料文件

- `PAPER_BLUEPRINT.md`：整篇论文的展开逻辑与跨问主线。
- `MATERIAL_POOL.md`：可直接进入正文的素材（推导、机制、对照、边界、示例）。
- `FIGURE_CATALOG.md`：允许进入论文的图及其用途/边界。
- `CITATION_PACKET.md`：只可用于既定目的的外部文献。

## 输出要求

写完后返回：

```text
paper/external-author/
├── draft.tex      # 即使材料有缺口也必须返回已有稿件
├── AUTHOR_NOTE.md # 可选：写作说明
└── AUTHOR_REQUESTS.json  # 可选：需要上游补的材料/图/证据/文献请求
```

禁止"缺少一张图所以什么都不交付"。素材缺口通过 `AUTHOR_REQUESTS.json` 提出，每项注明 `can_continue_without_it` 与 fallback。
